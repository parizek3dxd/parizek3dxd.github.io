FACT ENGINE

Runs in your browser. No account, no API keys, no server. Free unlimited voiceover, engine chosen automatically.

Read this first

Script: built from the intro of a Wikipedia article (CC BY-SA, credited below), or from a script you paste. There is no AI writer without a key, so it is extractive, not original. Edit any line.

Voice: free, unlimited, no API key, no account. The app automatically picks the first engine that works: Microsoft Edge neural voices (instant on desktop Edge/Chrome; Microsoft blocks iPhone Safari), a free shared OpenAI voice API (works on iPhone, up to ~17 s per sentence), or an on-device AI voice (Kokoro; first use downloads ~90 MB, then cached). Last fallback: basic offline voice.

Images: Wikimedia Commons only (free licenses, credited). No stock video without keys. You can add your own image per line.

Video: recorded live in your browser, so it takes as long as the video and the tab must stay open and visible. Output is MP4 where your browser supports it, otherwise WebM.

Download a track first, e.g. from pixabay.com/music (no credit needed), the YouTube Audio Library, or incompetech.com (credit required). Then pick the file here and check its license.
